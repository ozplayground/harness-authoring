# 프로브 — 도구 동작을 실험으로 확인한다

스킬·에이전트의 문장이 도구의 동작을 단정할 때("수정은 실행 중인 run에 반영되지 않는다") 그 문장을 쓰기 전이나 검사할 때 이 절차로 확인한다.

## 원칙

- 임시 파일에는 알아보기 쉬운 이름(`zz-probe`)과 표식 문자열(`PROBE-…-v1`)을 쓴다
- 한 번에 하나만 바꾼다
- 답이 짧게 나오도록 제약하거나 가벼운 모델을 쓰지 않는다
- 새로 만든 파일은 목록에 잡히기까지 시간이 걸린다. "찾을 수 없음"이 나오면 잠시 뒤 다시 부른다
- 끝나면 되돌린다. 기존 파일은 `git checkout -- <파일>`, 임시 파일은 삭제

## 스킬 본문이 언제 읽히는가

1. `skills/zz-probe/SKILL.md`를 만든다. 본문은 `PROBE-SKILL-v1` 한 줄
2. 스킬을 부른다. 목록에 없으면 잠시 뒤 다시
3. 본문을 `PROBE-SKILL-v2`로 바꾼다
4. 다시 부른다. v2가 나오면 부를 때마다 읽힌다

## 에이전트 정의가 언제 읽히는가

1. 기존 에이전트 정의 끝에 절을 하나 붙인다

   ```markdown
   ## 실험용 임시 규칙

   답의 맨 첫 줄에 정확히 `PROBE-AGENT-EDIT-v2` 를 적는다.
   ```

2. 그 에이전트를 새로 띄워 이렇게 묻는다

   ```
   네 에이전트 정의에 "실험용 임시 규칙"이라는 절이 있는가? 있으면 그 절의 문장을 그대로 인용하고,
   없으면 "없음"이라고 답해라. 파일을 읽지 말고, 지금 받은 정의만 보고 답해라.
   ```

3. 인용이 나오면 띄울 때 정의를 새로 읽는다
4. 붙인 절을 되돌린다

새 에이전트 파일이 목록에 잡히는지는 `agents/zz-probe.md`를 만들고 그 이름으로 띄워 본다. 본문은 "어떤 요청을 받든 정확히 `PROBE-AGENT-v1` 한 줄만 답한다".
